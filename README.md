# Portfolio

My personal portfolio website: a simple, dark-themed static site introducing me and my work in AI and machine learning.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Home page with an About section, project cards and contact area |
| `projects.html` | Projects page |
| `style.css` | Custom styles on top of Tailwind CSS |

## Built with

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- A little custom CSS

## Run it locally

No build step is needed. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
